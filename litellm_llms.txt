## project_purpose
LiteLLM is a Python library that acts as a proxy server for calling various large language model (LLM) APIs. It simplifies the process of interacting with different providers like OpenAI, Anthropic, Azure, and others by translating requests into the appropriate API calls, managing rate limits, and providing logging and observability features.

## key_concepts
Unified API Gateway: LiteLLM serves as a single entry point for multiple LLM providers, abstracting the complexity of interacting with each provider's API.
Provider Agnosticism: Supports a wide range of LLM providers, including OpenAI, Anthropic, Azure, Hugging Face, etc.
Cost Tracking and Budgeting: Enables tracking of API usage costs and setting budgets per project or user.
Rate Limiting: Implements rate limiting to control API usage and prevent overloading.
Logging and Observability: Integrates with tools like Langfuse, Helicone, and others to log and monitor API calls.
Routing and Load Balancing: Uses a router to distribute requests across multiple models or providers based on predefined strategies.
Security and Authentication: Provides mechanisms for secure access, including custom authentication and key management.

## architecture_overview
The architecture of LiteLLM consists of several components: a proxy server that handles incoming requests, a routing module that determines which provider/model to use, a translation layer that converts requests into the appropriate API format, and a logging/observability layer that tracks and records API interactions. The proxy server also manages user authentication, rate limiting, and budget tracking. The system is designed to be modular, allowing for easy integration with new providers and features.

## usage_examples
1. Initialize LiteLLM with OpenAI and Anthropic providers: `from litemll import LiteLLM; LiteLLM(providers=['openai', 'anthropic'])`
2. Set up rate limiting: `LiteLLM(rate_limit=100)`
3. Enable logging with Langfuse: `LiteLLM(loggers=['langfuse'])`
4. Route requests to different models: `LiteLLM(router='round_robin')`
5. Track API costs per project: `LiteLLM(cost_tracking=True)`
